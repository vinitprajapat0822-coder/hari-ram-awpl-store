# Hari Ram AWPL Store

Premium Ayurvedic & Wellness Products store with Liquid Glass UI and WhatsApp checkout.

## Features
- OS 27 Liquid Glass design system
- Product catalog (Asclepius / Wellroot products)
- Cart with quantity control
- Local user profile (Name, Phone, Address) - stored only on device
- One-click WhatsApp order with pre-filled bill
